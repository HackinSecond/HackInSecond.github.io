# Hackinsecond site: quick guide
1. Products, prices, contact info, typing phrases: top of `script.js`.
2. Replace `YOUR-USERNAME` in index.html, script.js (SITE.url), robots.txt, sitemap.xml, llms.txt.
3. Deploy: push to GitHub > Settings > Pages > Deploy from branch `main` / root.
4. After launch: add the site in Google Search Console and submit sitemap.xml.
5. Thumbnails: put images in assets/images/tools or courses and set `img:"tools/name.webp"` in script.js.
6. FAQ: if you edit it, change both the visible text and the FAQ block in index.html's JSON-LD.
